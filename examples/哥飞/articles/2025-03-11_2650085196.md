# 找出单月新增590万的网页：谷歌 Site 语法的五种用法，最后一种你绝对想不到

- 日期：2025-03-11 21:19
- 链接：https://mp.weixin.qq.com/s?__biz=MjM5OTIzMzYyMA==&mid=2650085196&idx=1&sn=d7e95c9f8e5725c081a30b92d97eb30f&chksm=bf3f26778848af61c0c3a6f31e608170d9ff571b1bb54ff5ff3944a791d9c7701d1901224b02

大家好，我是哥飞。
2023年9月，哥飞写了《分享几个实用的谷歌搜索高级语法》，里边也提到了 Site 语法，不过只讲了一种用法，今天这篇文章，我们讲讲 Site 语法的五种用法。

其中最后一种，能够有效的帮助你的网站更好的被谷歌收录。
第一种用法，你可以直接 site 域名后缀，如site:.org，就可以看到所有的用 org 域名的网页结果。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUY8yYicckwpq0ia3JhUGOG7usbCMttp24lLNDNkMCAI99C8k43APJXbmzw/640?wx_fmt=png&from=appmsg

用这个方法可以对比不同后缀的网页数量，从而判断要不要买某个小众后缀。
网页数量需要点击搜索框下方的 tools 才能看到。
第二种用法，大家就比较熟悉了，直接 site 某个域名，如site:github.io，看这个域名下的网页结果，和被收录的网页数量。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYdSIorHElibwjSdl2V7pTp4YqibMboouLZoMYDYwdswRkdsgzcMpicZ3JA/640?wx_fmt=png&from=appmsg

如果这个域名还提供子域名的话，第二种用法，还可以找出子域名。
第三种用法，查某个子域名下的网页结果。
上周我们分享一个最近流量暴增的 github.io 子域名 iseej.github.io ，如果你直接打开首页，会发现 404 了。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYhVdwVQciaZxSz4GgeK8hm7PNZiclFZq2ab1E2t0LzZn9JcRicZgYoeAvw/640?wx_fmt=png&from=appmsg

其实是因为他没有配置首页，只配置了内页，那么怎么找到他的内页呢？就可以用site:iseej.github.io实现。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYIHMNIagOm6UQMJsib1rGr2b4SicFI3UzhY7Rg3m3MQkva2Het76icWJWg/640?wx_fmt=png&from=appmsg

可以看到，这个域名在2月有592万的访问量，而1月的访问量是2万。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYamLJwnYwNP2KHWO67BWGwWqNq6NdpCz5cOvT6kibIHjaQvXcEax9zvQ/640?wx_fmt=png&from=appmsg

从2万到592万，是怎么做到的呢？刚才 site 查询出来的结果里就有答案。
第四种用法，查询某个域名下的某个目录下的结果，如 V2EX 就用这个做站内搜索。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYbdpplEKNt3Y7aCHlt5rrwrChYdoR6gwqNuBqLibIKG0bN7hiaSKRDF7w/640?wx_fmt=png&from=appmsg

site:v2ex.com/t表示搜索域名 v2ex.com 下以 /t 为开头的网页

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYYwmsGibSjdicicejEvqliaVr6dxdticiaS4adrkWWw5xReXU52MvtImwx01g/640?wx_fmt=png&from=appmsg

第五种用法，直接查询某个 url ，主要用途是看是否被收录了，看显示出来的标题、描述、图标等是否正确。
杉木哥的 toolify.ai 就用这个方法判断最新发布的页面是否被收录了。
如果没有被收录，则继续在首页曝光，尽量让谷歌爬虫看到，增加被收录的几率。
如下面是没被收录的页面 site 结果：

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYEvUGHou6Hrp3Iv88h9y5ReuX43HWlPVQOHE3icOvia9HNLHJOV57Ffag/640?wx_fmt=png&from=appmsg

如下面是已经被收录的页面 site 结果：

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeicsxsVzBhySu9lvFOaBmDnUYufsjnVU6puTZwtJIiarPRtWHiaN2zwjNhO6yrju6OvibER0WycceYdJbA/640?wx_fmt=png&from=appmsg

这套方法，被杉木哥称为“炒豆子法”，炒豆子时经常翻动，就可以确保加热均匀，让每一颗豆子都有均匀受热的机会。

Toolify.ai 能够被收录一百多万个页面，这个方法是起了很大作用的。
