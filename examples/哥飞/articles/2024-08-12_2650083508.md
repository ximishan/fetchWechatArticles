大家好，我是哥飞。
今天我们接着昨天的教程，来说一说，怎么快速把《【哥飞推荐】新人友好完全无需数据却有管理后台，可以动态更新网站内容的开源CMS》提到的CMS给安装部署起来。

在安装部署之前，大家需要提前准备好 Vercel 账号和 Github账号。

如果你没有准备好，请先跟着哥飞之前的教程走一遍：
如何 10 分钟上线一个 AI 导航网站？

如果你已经准备好了，那么就可以跟着哥飞的步骤一步一步开始了。

https://github.com/qiayue/GitBase

这时候你如果打开你的 Github账号，是可以看到你刚刚部署好的这套代码对应的仓库的，仓库名称就是哥飞之前填写的 blog 。

用浏览器打开 Vercel 分配的子域名，就可以看到我们刚刚部署完成的网站了，是不是特别快，我们只是点击了几个按钮，输入了一下仓库名称，再等待了一分钟左右，网站就部署好了。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMfQ7kNiawZRxcFaiaeQBuPlZPgY2JPfjbAD6RBx8MvHZyCHVna6UnuiaGw/640?wx_fmt=png&from=appmsg

恭喜你，现在有了人生中的第一个网站，但是你会看到网站上面的内容暂时还是哥飞内置好的，如果你想去修改，要怎么改呢？
下面的步骤虽然看起来多，但其实不复杂，你跟着哥飞一步一步走就行了。

第五步，你需要去获取你的 Github 的个人 Token ，你需要打开 https://github.com/settings/tokens ，创建个人 classic token 。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMnznqOEBn9zzu3gWsGyNr6UQ9fdLOLha6WicZuibXNTlkfXqO2BiapAcZw/640?wx_fmt=png&from=appmsg

第六步，输入 token 名称，选择失效时间，勾选 repo ，然后点击页面底部的“Generate token”绿色按钮。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMfB7FMoZNFuu7icJ707gvey0DApn5oKpicKicUaOvHCm1cStVj0hDqaJBg/640?wx_fmt=png&from=appmsg

第七步，复制 token 备用，注意，这个 token 打死都不能告诉别人。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMBq3TPAm6sM5xNWRuoncTPZJBSkROuia0DYSwWsRujvSFuwRMvibePAYA/640?wx_fmt=png&from=appmsg

第八步，打开Vercel项目设置页面。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMHTmoHZqjDUa2yBLhIrq9t4h7xkyiaC0OJeQbJqnBopILtCxpbsSs4FQ/640?wx_fmt=png&from=appmsg

按照下面这篇教程的要求配置 Vercel 的环境变量。
https://gitbase.app/posts/environment-variables

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMibiarfibyWr8nmcib4ENriaoUeX8MgwkkKxHMgxC0VxaNBjjtVKYa2papxQ/640?wx_fmt=png&from=appmsg

注意六个环境变量一个都不能少，其中 DOMAIN 因为我们目前还用的是 Vercel 的子域名，所以就填子域名，如果后面你改成用自己的域名，就需要填自己域名。
填完之后，应该是下面这样的：

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMuvyU7Le3v7XFuNibUyzbXKxXZ3ic3nQKJ2ia9P8odXEjq3OxrqmUQZozA/640?wx_fmt=png&from=appmsg

第九步，因为我们刚才配置了环境变量，所以需要重新去 Vercel 再部署一次，环境变量才会生效。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQM8jRFFkfNT52u32LjIQH8mCZ1bse37s9m29MhDC9ogSicTmsTCFln2bg/640?wx_fmt=png&from=appmsg

在弹出的浮层里点击一下“main”，然后点击“Create Deployment”按钮就会触发重新部署，等待部署完成。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMFk4pt9erN25P7hc91ARTcOvHNicQLuHrajNkxEm7ezPr6O8fSgVRHmw/640?wx_fmt=png&from=appmsg

第十步，现在可以打开我们自己网站的后台了，先点击导航栏右侧的登录按钮，进入登录页面

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQM1QPm17B1cDxhKkU6N0VWM6JcWs1HiamLLadHddWbIEyCPxxvlicAfqGg/640?wx_fmt=png&from=appmsg

如果你看到了下面这个界面，那么就是成功登录到管理后台了。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMCayDGFhFp4YcZlcY3iaYlARzDsYCib0XLGDVDYWbOdwJHQmcCMuC4R2A/640?wx_fmt=png&from=appmsg

你可以在这个页面管理资源列表，也即是导航列表。

还可以点击“Mange Articles”按钮，进入文章管理列表。

如果在文章列表，你没有看到文章，那么需要手动点击同步按钮，一会儿就能看到文章列表了。

[IMG] https://mmbiz.qpic.cn/sz_mmbiz_png/LBrX00GQeics2vSeC71W61roofRjDkpQMQhSHw1UKOzuTU17n87BIrTAAg2bU2cFgUfe3P7dIZu6zcZh6Qmxr7Q/640?wx_fmt=png&from=appmsg

之后你可以修改文章，可以写新文章。
